
# 🎯 Acerte o Alvo
Um mini game simples feito com **React + Vite + Tailwind CSS**.
## Como jogar
- Um alvo 🎯 aparece em uma das 9 casas.
- Clique nele o mais rápido possível para ganhar 1 ponto.
- Você tem **30 segundos**.
- Quanto mais pontos, mais rápido o alvo muda de lugar.
- O seu **recorde** fica salvo no navegador (localStorage).
## Como rodar
```bash
npm install
npm run dev
```
Para gerar a versão de produção:
```bash
npm run build
```
